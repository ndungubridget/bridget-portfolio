## Getting Started

To view the project locally:

1. Clone the repository.

```bash
git clone https://github.com/ndungubridget/bridget-portfolio.git
```

2. Open the project folder.

```bash
cd bridget-portfolio
```

3. Open `index.html` in your browser.

You also can open the project in Visual Studio Code and use Live Server to view the website.
